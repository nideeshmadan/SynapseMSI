# Documentation

Explanatory documentation for SynapseMSI External Reconstruction.

Normative requirements live under `../specifications/`. This directory explains architecture, reconstruction boundaries, historical acquisition context, and how to reproduce the published investigation packages.

## Contents

| Document | Purpose |
|----------|---------|
| `architecture.md` | Reconstruction pipeline, investigation bundles, and determinism |
| `historical-acquisition-regimes.md` | Historical acquisition-regime inventory and interpretation (non-normative) |
| `investigation-reproducibility.md` | Worked reproduction guide for the five public investigation packages |
| `reconstruction-boundaries.md` | Evidentiary scope, supported conclusions, and interpretation boundaries |

## Normative versus explanatory

The documents in this directory explain and contextualize the repository but do not define normative requirements.

Normative requirements are defined under `../specifications/`. See `../specifications/README.md`.
